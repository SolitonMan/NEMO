Requests and Requirements

Use this page to make and track requests for training, or for services like characterization and analysis. Click the Submit a request button to launch the request wizard and step through making a request:
  1. Select the core
  2. Select the request type
  3. Select the project to charge
  4. Describe the purpose of the request (and indicate if it's a training request for MCL)
  5. Submit the request
Requests may have requirements that need to be fulfilled before the service can be undertaken or the training can commence. Requirements assigned to you can be managed by clicking the blue Requirements Management button. Some requirements are automatically updated based on your activities, while other require manual confirmation of completion. In those cases you'll be asked to digitally sign the completion confirmation using your LEO email address.
